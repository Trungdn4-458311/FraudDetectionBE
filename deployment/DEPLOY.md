# Deploy the live demo — end-to-end guide (Hugging Face Spaces, free tier)

The rubric requires a **live, accessible link** to the deployed API + review-queue demo.
This walks you through it from zero. Two routes: **A) web UI (easiest)** and
**B) git/CLI (reproducible, scriptable)**. Both give a public URL like
`https://huggingface.co/spaces/<user>/fraud-detection-demo`.

The Space runs the **Streamlit review queue** (`app.py`), which scores transactions
with the same `scoring.py` core as the API — so one Space satisfies the "deployed
demo" deliverable. (To also expose the FastAPI `/predict` endpoint publicly, use the
**Docker-SDK** variant in the last section.)

> Prerequisite either way: `deployment/model.joblib` must exist. It is generated by the
> notebook (`pixi run notebook`, or Restart & Run All through Module 6) and is **committed to
> the repo**, so it is already present for the Space — regenerate it only if you retrain.

---

## Route A — Web UI (5 minutes, no tooling)

1. **Create an account:** sign up at <https://huggingface.co/join>.
2. **New Space:** <https://huggingface.co/new-space> →
   - *Owner*: you · *Space name*: `fraud-detection-demo`
   - *License*: mit (or as you prefer)
   - *SDK*: **Streamlit**
   - *Hardware*: **CPU basic (free)** · *Visibility*: **Public**
   - Click **Create Space**.
3. **Upload files:** in the Space, **Files → Add file → Upload files**, and upload the
   contents of the `deployment/` folder:
   `app.py`, `api.py`, `scoring.py`, `requirements.txt`, `sample_transactions.csv`,
   **`model.joblib`**, and `README.md` (its YAML header configures the Space).
   Commit.
4. The Space builds (installs `requirements.txt`) and starts `app.py`. When the status is
   **Running**, the public URL at the top is your **live link**.
5. **Cite the link** (deliverable): put it in the root `README.md`,
   `report/main.tex` (Section "Deployment"), and the slides.

## Route B — git / CLI (reproducible)

You need a **write token**: <https://huggingface.co/settings/tokens> → **New token** →
type **Write** → copy it (`hf_...`).

```bash
# 1. Log in once (stores the token locally; never paste it into source files)
pip install --upgrade "huggingface_hub[cli]"
huggingface-cli login            # paste the write token when prompted

# 2. Create the Space (Streamlit SDK)
huggingface-cli repo create fraud-detection-demo --type space --space_sdk streamlit -y

# 3. Push the deployment/ folder to it
HF_USER=$(huggingface-cli whoami | head -1)
git clone "https://huggingface.co/spaces/$HF_USER/fraud-detection-demo" hf-space
cp deployment/{app.py,api.py,scoring.py,requirements.txt,sample_transactions.csv,README.md,model.joblib} hf-space/
cd hf-space
git lfs install
git lfs track "*.joblib"         # optional (model.joblib is <1 MB; LFS only required >10 MB)
git add -A && git commit -m "Deploy fraud-detection review queue"
git push
echo "Live link: https://huggingface.co/spaces/$HF_USER/fraud-detection-demo"
```

The `README.md` YAML header (`sdk: streamlit`, `app_file: app.py`) tells the Space how to run.

---

## Verify the live deployment

- Open the URL → the review queue loads, "Mẫu có sẵn" shows the scored sample queue with the
  three-tier decisions (auto-block / manual-review / auto-approve).
- If it fails to build: check **Logs** in the Space. Common causes: `model.joblib` missing
  (upload it / LFS-track it), or a `sdk_version` that no longer exists (bump it in `README.md`).

## Optional — expose the FastAPI endpoint too (Docker SDK)

A Streamlit Space can't also serve FastAPI. To publish `/predict` publicly, deploy the
included `Dockerfile` as a **Docker** Space:

1. New Space → SDK **Docker** → Public.
2. Push `deployment/*` **plus** the repo-root `Dockerfile` (copy it into the Space).
3. In the Space `README.md` header set `sdk: docker` and `app_port: 7860`.
4. The container serves the API on `/` (docs at `/docs`).

Locally the same image runs with:

```bash
docker build -t fraud-demo .
docker run --rm -p 8501:8501 fraud-demo          # Streamlit review queue
docker run --rm -p 8000:8000 -e PORT=8000 fraud-demo api   # FastAPI (http://localhost:8000/docs)
```
